# Background image – prompt for AI image generator

Use this prompt to generate a **space background** for the game (place the result as `space_bg.png` in this folder).

---

**English prompt:**

```
Deep space background, cosmic void, dark navy and midnight blue gradient, subtle purple and indigo tones, starfield with very faint distant stars, no bright lights, no nebula glow, no planets, no cartoon style, photorealistic or matte painting style, calm and mysterious atmosphere, premium minimalist look, 16:9 or 9:16 aspect ratio, static image, no motion blur, no particles, suitable for mobile game UI background.
```

---

**Short variant:**

```
Dark space background, navy blue and deep purple gradient, sparse faint stars, minimalist, calm, premium, no glow, no cartoon, static, mobile game background.
```
