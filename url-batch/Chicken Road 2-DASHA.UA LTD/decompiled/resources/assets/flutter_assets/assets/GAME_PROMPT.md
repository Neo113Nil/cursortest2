# Celestium Path — Game Prompt (English)

**Celestium Path** is a premium mobile maze puzzle game set in a deep-space, interstellar civilization. The player navigates through cosmic labyrinth structures built by an ancient advanced culture. The atmosphere is minimalistic, architectural, and futuristic—calm and intelligent, with no cartoon or childish visuals. The visual style uses a dark palette: deep space black, midnight navy, soft neon cyan accents, silver gray, and nebula purple. All UI updates are instant; there are no animations, transitions, or decorative effects anywhere in the app.

The core gameplay is **Find the Exit**: a top-down, grid-based maze where the player moves tile by tile using four directional buttons (Up, Down, Left, Right). Movement is immediate with no swipe or joystick. The player cannot pass walls and must reach the Exit Portal to complete a level. Optional mechanics include keys that unlock gates, teleport tiles that swap position with a paired tile, and trap tiles that reset the player to the start. Each level has a move limit; exceeding it counts as failure and shows a “Navigation Failed” dialog with Retry and Level Select. Reaching the exit counts as success and opens a “Sector Cleared” victory dialog showing level number, moves used, efficiency rating (Standard / Advanced / Elite), and star rating (1–3), with buttons for Next Level and Level Select.

The game has **45 levels** in three chapters. **Orbital Sector** (levels 1–15) offers clean geometric mazes and small to medium grids. **Nebula Complex** (levels 16–30) introduces more complex layouts, dead ends, and branching paths. **Obsidian Core** (levels 31–45) features larger labyrinths, higher difficulty, multi-route structures, trap tiles, and locked gates with keys. Levels unlock sequentially. Before gameplay, a full-screen Level Select screen shows all levels by chapter, with locked levels disabled, completed levels marked with stars, the current level highlighted, and completion percentage per chapter.

The app includes a **Welcome screen** (first launch only) with a premium space background, app title, subtitle, and “Enter Sector” button; a **Home screen** with app title, Continue, Level Select, Achievements, Settings, and progress summary; the **Game screen** with chapter name, level number, moves used, move limit, maze grid, and directional controls; an **Achievements screen** with 15 achievements (e.g. First Sector Cleared, 10/30/45 levels completed, chapter completion, Elite Navigator, Master of Labyrinth); and a **Settings screen** with sound toggle, reset progress (with confirmation), and theme accent selector (Cosmic Blue, Nebula Purple, Silver Obsidian). All screens have a back button where applicable. Victory and failure dialogs appear instantly with no animation.

Progress is saved locally with **Hive**: onboarding state, unlocked and completed levels, stars and move statistics per level, unlocked achievements, sound preference, and theme selection. The project uses **Flutter** with null safety, **Riverpod** for state management, and a **Clean Architecture** layout (core, models, services, storage, screens, widgets, game, utils). The app name and package name remain fixed. Assets include a deep-space background image for welcome and home screens, and an assets folder with prompts for generating background and app icon. The game is production-ready, fully runnable, and uses only English in the UI.
