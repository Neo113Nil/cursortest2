# Asset generation prompts — Celestium Path

Use these prompts with an AI image generator (e.g. DALL·E, Midjourney, Stable Diffusion) or brief a designer.  
App theme: **Deep Space / Interstellar Civilization / Cosmic Architecture**.  
Style: **Premium, minimalistic, architectural, futuristic, calm**. No cartoon, no childish visuals, no flashy effects.

---

## 1. Background (welcome / full-screen)

**Suggested filename:** `assets/backgrounds/welcome_bg.png`  
**Aspect:** Portrait, 9:16 or similar (mobile full-screen).  
**Use:** Welcome screen and optionally home screen background.

**Prompt:**

```
Deep space background for a premium mobile game. Interstellar void, very dark navy and black gradient. Subtle cosmic architecture: faint geometric grid or hexagonal structure receding into the distance, like an ancient alien station. Minimalistic, calm, no stars, no particles, no glowing effects. Moody, cinematic, high-end sci-fi. Wide aspect ratio cropped for vertical mobile screen. No text, no characters. Moody blue and black only, very low saturation.
```

**Shorter variant:**

```
Dark deep space background, midnight navy and black, subtle futuristic geometric structure in the void, minimalistic, calm, no stars or particles, premium sci-fi game art, vertical mobile format.
```

---

## 2. App icon (launcher icon)

**Suggested filename:** `assets/icons/app_icon.png` (then use for Android `mipmap` / iOS `Assets.xcassets`).  
**Size:** 1024×1024 px (export smaller variants from this).  
**Use:** App launcher icon on device home screen.

**Prompt:**

```
App icon for a puzzle game called "Celestium Path". Deep space theme: a single elegant path or corridor shape (minimal line or wedge) leading into a soft glow or portal, on dark navy/black. Icon style: flat, minimal, premium. One subtle accent color: soft cyan or nebula purple. Must read clearly at 48px and 192px. No text, no rocket, no character. Geometric, architectural, calm. Square format, no rounded corners in the image itself.
```

**Shorter variant:**

```
Minimal app icon, dark space background, one simple geometric path or portal shape, soft cyan or purple accent, premium game icon, readable at small size, square.
```

---

## Optional: in-game assets

If you later add image assets for maze tiles or UI:

- **Player:** Minimal rocket or craft silhouette, same color palette (e.g. soft cyan on dark).
- **Exit portal:** Simple geometric “gate” or “portal” shape, nebula purple or cyan.
- **Keys / gates:** Abstract key and lock shapes, metallic gray and gold accent, no cartoon style.

Keep all assets **consistent**: same dark navy/black base, limited accent colors (cyan, purple, silver).
