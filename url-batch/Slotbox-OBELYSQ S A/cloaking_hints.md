# Cloaking hints

- Play / карточка: `Slotbox`. application-label в APK: `Win`.
- Package: `com.moss.bloom.coil.curtain.trail.slotbox`.
- Белая оболочка по витрине: «Win» — творческие / визуальные задания, а не слоты. Текст карточки начинается с «Win gives access to a rich world of creative ideas…».
- Скан APKCube (сборка 1.0 / vc 97, sha256 APKS `9d0db797fe696e0570c3ac29c085325d166fa3112629684234f28d1d9493d939`): INTERNET, ACCESS_NETWORK_STATE, VIBRATE, CHECK_LICENSE, PairIP, DYNAMIC_RECEIVER_NOT_EXPORTED.
- minSdk Android 8.0+ (API 26), target Android 16 (API 36), APKS ~5 MB, arm64-v8a.
- Готовая проверка доменов пустая. Точный адрес гейта из бинаря не снят: папка collector на origin не приехала, APKPure 404, APKCube Hold-to-verify / download-token 403 (файл не сохранён).
- Клоака = да из-за расхождения имён, сети и проверки лицензии PairIP, не из-за прочитанного URL оффера.
