# Проверка подозрительных доменов

Кастомных/неизвестных хостов нет. Домены RevenueCat (`api.revenuecat.com`, `api-diagnostics.revenuecat.com`, `api-paywalls.revenuecat.com`, `api.rc-backup.com`, `api-production.8-lives-cat.io`) — известный SDK покупок, в таблицу «Подозрительные домены» не входят. `base44.app` / `base44.com` — платформа самого приложения (сайт разработчика на карточке Play).
