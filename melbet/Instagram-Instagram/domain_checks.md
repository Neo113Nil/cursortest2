# Проверка подозрительных доменов

Подозрительных (кастомных/неизвестных) доменов нет.

В промпте были VT-таблицы для about.fb.com, about.meta.com, accounts.spotify.com,
ai.character.app, ai.meta.com — это крупные известные сервисы Meta/Facebook/Spotify/Character.AI,
их нельзя включать в «Подозрительные домены» по правилам отчёта.
