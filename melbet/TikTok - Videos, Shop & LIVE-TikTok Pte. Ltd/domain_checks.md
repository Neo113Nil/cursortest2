# Проверка подозрительных доменов

Подозрительных (кастомных/неизвестных) доменов нет.

Хосты из промпта VT (`accounts*.tokopedia.com`, `*.tiktokv.com` и т.п.) —
офименны первого лица TikTok/ByteDance и Tokopedia (крупный e-commerce /
партнёр TikTok Shop). По правилам отчёта они исключены из строки
«Подозрительные домены»; отдельные таблицы «Проверка домена» не строятся.
