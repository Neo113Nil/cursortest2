# Проверка подозрительных доменов

Подозрительных (кастомных/неизвестных) доменов нет.

В промпте были VT-таблицы для about.meta.com, accounts.spotify.com,
accountscenter.meta.com, aomedia.org, apps.fbsbx.com (обрезано) —
это крупные известные сервисы Meta/Facebook/Spotify/Alliance for Open Media,
их нельзя включать в «Подозрительные домены» по правилам отчёта.
