# Проверка подозрительных доменов

Подозрительных (кастомных/неизвестных) доменов нет.

Хосты из промпта исключены как известные сервисы Google/стандарты или отсутствующие в APK:
- aomedia.org — Alliance for Open Media (AV1 emsg namespace в коде)
- chromium.org / chromestatus.com — Google Chrome / Chromium
- bit.ly — известный сокращатель ссылок (в бинарнике не найден)
- bar.com — в строках APK не найден
