# Проверка подозрительных доменов

Подозрительных (кастомных/неизвестных) доменов для VT-таблиц нет.

В APK встречаются только хосты известной платформы билдера Andromo (`sqz.andromo.com`, `builder.andromo.com`, `inapppurchase.andromo.com`) и крупных SDK (Flurry, Sentry, Google). Отдельных obscure gate/offer-хостов нет.
